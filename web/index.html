Get the browser extension — Chrome & Edge

Check the current page from your toolbar, or paste a suspicious email. Offline pattern checks run locally. For live checks, the extension opens the secure web app, where you can review and scan the domain or email. No background browsing access.

↓ Download browser extension (.zip)
  1. Download and extract the ZIP.
  2. Open chrome://extensions or edge://extensions.
  3. Turn on Developer mode, select Load unpacked, and choose the extracted folder containing manifest.json.
  4. Pin PhishLens to your toolbar. Open it and select Use current page.

This is a locally installed extension, not a Chrome Web Store listing.
